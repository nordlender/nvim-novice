# Neovim Novice
This is my personal config which I would call the config of a novice. At this point I have most things down, and LSPs should work better. After some time without updating my config to match updates of packages used I realized I needed to start fresh, so here we are, having migrated some of my favorite parts.

## Features
- Lazy loading
- Vimtex for LaTeX
- Snippets
- Cool color changing toolbar for the neurodivergent bros, should prolly be reworked
- Swag
